# US-Rank-01：段位维护

## 基本信息

| 项目 | 内容 |
|:---|:---|
| 故事编号 | US-Rank-01 |
| 模块 | 段位维护（rank） |
| 优先级 | P0 |
| 状态 | 待开发 |

---

## 用户故事描述

**作为** `一名管理员`，

**我想要** `对系统中的段位等级进行全生命周期管理（查看列表、新增、编辑、删除）`，

**以便于** `灵活配置积分体系的段位规则，确保积分段位体系可维护、可调整`。

---

## 功能范围概览

本用户故事包含以下 4 个子功能：

| 子功能 | 操作入口 | 简要说明 |
|:---|:---|:---|
| **查看段位列表** | 进入「段位维护」页面自动加载 | 表格展示所有段位记录（段位图标、段位名称、积分区间、当前段位人数、操作按钮），按积分下限降序排列 |
| **新增段位** | 点击「新增段位」按钮 | 弹窗表单填写段位图标、名称、积分区间并创建 |
| **编辑段位** | 点击行内「编辑」按钮 | 弹窗回显当前数据并修改保存 |
| **删除段位** | 点击行内「删除」按钮 | 二次确认后移除该段位记录 |

---

## 一、查看段位列表

#### 正常流程（Happy Path）

1. 管理员 进入「段位维护」页面
2. 系统自动加载并展示所有段位记录，按**积分下限降序**排列
3. 系统在表格中展示每条段位记录的段位图标、段位名称（含段位颜色标签）、积分区间（下限-上限）、当前段位人数
4. 管理员 可查看不同段位对应的颜色标识（如王者为金色、钻石为蓝色、星耀为紫色等）

#### 异常流程

| 场景 | 系统响应 |
|:---|:---|
| 无段位数据 | 表格区域显示「暂无数据」占位文本，分页栏仍正常显示 |

#### UI 交互说明

- 页面结构为：顶部标题行「段位维护列表」→ 下方「新增段位」按钮（左对齐）→ 数据表格 → 底部分页组件
- 表格列顺序：段位图标（居中）、段位名称、积分区间、当前段位人数（居中）、操作（居中）
- 操作列包含「编辑」和「删除」两个文字链接
- 分页栏左侧显示总条数和每页条数下拉（10/20/50/100，默认20），右侧显示翻页按钮和跳转输入框
- 总页数 ≤ 1 时分页栏仍然显示
- 段位名称以颜色标签形式展示，不同段位对应不同背景色

## 二、新增段位

#### 正常流程（Happy Path）

1. 管理员 点击「新增段位」按钮
2. 系统弹出「新增段位」模态框，包含段位图标选择器、段位名称输入框、积分下限输入框、积分上限输入框
3. 管理员 在图标选择器中点选一个 Emoji 图标
4. 管理员 填写段位名称、积分下限和积分上限
5. 系统实时校验字段合法性，若区间与相邻段位存在间隙则显示黄色提示，若连续则显示绿色提示
6. 管理员 点击「确认」按钮
7. 系统完成段位创建，关闭弹窗，显示 Toast「新增成功」，自动刷新列表

#### 异常流程

| 场景 | 系统响应 |
|:---|:---|
| 段位图标未选择 | 前端即时校验，图标选择器下方显示「请选择段位图标」 |
| 段位名称为空 | 前端即时校验，输入框下方显示「请输入段位名称」 |
| 段位名称与已有段位重复 | 前端提交校验/后端返回 400，输入框下方显示「段位名称已存在，请更换」 |
| 积分下限为空或非数字 | 前端即时校验，输入框下方显示「请输入有效的积分下限」 |
| 积分下限小于 0 | 前端即时校验，输入框下方显示「积分下限不能小于0」 |
| 积分上限为空或非数字 | 前端即时校验，输入框下方显示「请输入有效的积分上限」 |
| 积分上限 ≤ 积分下限 | 前端即时校验，输入框下方显示「积分上限必须大于下限」 |
| 积分区间与现有段位重叠 | 前端提交校验/后端返回 400，输入框下方显示「积分区间与「{重叠段位名}」重叠，请调整」 |
| 网络/服务不可用 | Toast 提示「新增失败：网络异常，请重试」 |
| 权限不足 | 后端返回 403，提示「您没有权限执行此操作」 |

#### UI 交互说明

- 点击「新增段位」按钮 → 弹出模态框，标题为「新增段位」
- 弹窗宽度 520px（字段数 ≤ 4）
- 表单布局为单列纵向排列，字段顺序：段位图标选择器 → 段位名称 → 积分下限 → 积分上限
- 段位图标选择器为平铺网格布局，包含至少 16 个常用 Emoji 图标选项，点选后高亮显示
- 必填字段标签前显示红色 `*`，对应输入框背景为浅黄色
- 积分下限/上限输入后，系统自动检测区间连续性并在积分上限下方显示提示
- 底部操作按钮：「取消」（灰色默认按钮）在左，「确认」（蓝色主按钮）在右
- 弹窗支持点击遮罩层或右上角关闭按钮关闭
- 确认按钮在提交期间禁用，防止重复提交
- 弹窗关闭时清空表单数据和校验状态

## 三、编辑段位

#### 正常流程（Happy Path）

1. 管理员 点击某段位行内的「编辑」按钮
2. 系统弹出「编辑段位」模态框，自动回填当前行的段位图标、段位名称、积分下限、积分上限
3. 管理员 修改需要调整的字段
4. 系统实时校验字段合法性，若区间与相邻段位存在间隙则显示黄色提示，若连续则显示绿色提示
5. 管理员 点击「确认」按钮
6. 系统完成段位更新，关闭弹窗，显示 Toast「编辑成功」，自动刷新列表

#### 异常流程

| 场景 | 系统响应 |
|:---|:---|
| 段位图标未选择 | 前端即时校验，图标选择器下方显示「请选择段位图标」 |
| 段位名称为空 | 前端即时校验，输入框下方显示「请输入段位名称」 |
| 段位名称与其他段位重复 | 前端提交校验/后端返回 400，输入框下方显示「段位名称已存在，请更换」 |
| 积分下限为空或非数字 | 前端即时校验，输入框下方显示「请输入有效的积分下限」 |
| 积分下限小于 0 | 前端即时校验，输入框下方显示「积分下限不能小于0」 |
| 积分上限为空或非数字 | 前端即时校验，输入框下方显示「请输入有效的积分上限」 |
| 积分上限 ≤ 积分下限 | 前端即时校验，输入框下方显示「积分上限必须大于下限」 |
| 积分区间与其他段位重叠 | 前端提交校验/后端返回 400，输入框下方显示「积分区间与「{重叠段位名}」重叠，请调整」 |
| 并发编辑/数据已不存在 | 后端返回 400，Toast 提示「段位数据已被修改或删除，请刷新后重试」，自动刷新列表 |
| 网络/服务不可用 | Toast 提示「编辑失败：网络异常，请重试」 |
| 权限不足 | 后端返回 403，提示「您没有权限执行此操作」 |

#### UI 交互说明

- 点击行内「编辑」按钮 → 弹出模态框，标题为「编辑段位」
- 弹窗宽度 520px（字段数 ≤ 4），与新增弹窗共用同一表单结构
- 弹窗打开时自动回填当前行所有可编辑字段：图标选择器选中对应图标、输入框回填名称和积分值
- 其余交互规范与新增弹窗一致（校验、按钮、关闭、防重复提交等）

## 四、删除段位

#### 正常流程（Happy Path）

1. 管理员 点击某段位行内的「删除」按钮
2. 系统弹出「确认删除」模态框，根据关联成员数量动态显示提示文案
3. 管理员 点击「确认删除」按钮
4. 系统完成段位删除，关闭弹窗，显示 Toast「删除成功」，自动刷新列表

#### 异常流程

| 场景 | 系统响应 |
|:---|:---|
| 该段位下有成员（n > 0） | 确认弹窗显示：`确定要删除段位「{名称}」吗？该段位下当前有 {n} 名关联成员，删除后相关成员将受影响。` |
| 该段位下无成员（n = 0） | 确认弹窗显示：`确定要删除段位「{名称}」吗？此操作不可撤销。` |
| 并发删除/数据已不存在 | 后端返回 400，Toast 提示「段位已被删除，请刷新列表」，自动刷新列表 |
| 网络/服务不可用 | Toast 提示「删除失败：网络异常，请重试」 |
| 权限不足 | 后端返回 403，提示「您没有权限执行此操作」 |

#### UI 交互说明

- 点击行内「删除」按钮 → 弹出确认模态框，标题为「确认删除」
- 弹窗宽度 420px
- 弹窗内容区包含警告图标 + 提示文案，文案根据关联成员数量动态生成
- 底部操作按钮：「取消」（灰色默认按钮）在左，「确认删除」（红色危险按钮）在右
- 弹窗支持点击遮罩层或右上角关闭按钮关闭
- 点击「取消」关闭弹窗，不做任何操作

## 不在本故事范围内

- 批量编辑/批量删除 → 当前版本不支持
- 拖拽排序 → 当前版本不支持
- 编辑历史/版本回溯 → 当前版本不支持
- 用户段位自动更新 → 由后端积分维护模块处理
- 首页段位统计卡片联动 → 由首页模块处理
- 导入/导出段位配置 → 当前版本不支持
