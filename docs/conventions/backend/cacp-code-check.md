# cacp项目Sonar扫描项规则

## 概述

本文档参照 Sonar 要求制定。

# 一、Java 编码要求

## 1.1 通用规则（业界规范）

### 控制流

| 序号 | 规则 | 说明 |
|------|------|------|
| 1 | switch 没有 break 语句 | switch case 应有 break，防止贯穿 |
| 2 | 周年不应用于日期格式化 | 使用 Year 或 Month 替代 |
| 3 | 非短路逻辑检查 | 使用 `&&`/`\|\|` 而非 `&`/`\|` |
| 17 | 锁应该被释放 | 确保 lock 在 finally 中释放 |
| 23 | 错误赋值运算符 | 避免 `if(x = y)` 而非 `if(x == y)` |
| 24 | 无用的返回值 | 不要忽略有返回值的方法 |
| 26 | 不应调用 Object.wait() | 在非同步块中调用会抛异常 |
| 29 | 集合不应调用自己 | 避免无限递归 |
| 33 | 不应该执行愚蠢的位操作 | 位运算应有实际意义 |

### 线程与同步

| 序号 | 规则 | 说明 |
|------|------|------|
| 4 | 同步不应基于字符串或装箱原语 | 字符串池和装箱机制会导致同步失效 |
| 8 | 不应在字段本身同步 | 使用专用锁对象 |
| 12 | 持有两个锁时不应调用 wait 方法 | 可能导致死锁 |
| 14 | 不应在线程实例上调用 wait(...) | 应在锁对象上调用 |
| 15 | ScheduledThreadPoolExecutor 不应有 0 个核心线程 | 0 核线程池会立即关闭 |
| 20 | 不应将基于值的类用于锁定 | 如 Integer、String 池 |
| 21 | "getClass" 不应用于同步 | 使用 `this.getClass()` 而非字面量 |
| 31 | Thread.run() 不应直接调用 | 应使用 start() 启动线程 |

### 方法命名与重载

| 序号 | 规则 | 说明 |
|------|------|------|
| 5 | 方法不应命名为 "equal" | 与 Object.equals() 混淆 |
| 10 | 方法不应命名为 "hashcode" 或 "equal" | 同上 |
| 28 | 疑惑的重载 | 参数类型相似容易混淆 |

### 面向对象

| 序号 | 规则 | 说明 |
|------|------|------|
| 6 | 无效的时间值 | 检查 Date/Calendar 值的有效性 |
| 7 | 子类字段不应覆盖父类字段 | 导致意外行为 |
| 9 | toString() 返回 null | 应返回空字符串或默认值 |
| 16 | super.finalize() 应在 Object.finalize() 实现的末尾被调用 | 确保父类资源释放 |
| 18 | 重载 Object.finalize() | 重写时应调用 super.finalize() |
| 19 | compareTo 不应该被重载 | 应返回负数、零、正数 |

### 数据库

| 序号 | 规则 | 说明 |
|------|------|------|
| 11 | PreparedStatement 和 ResultSet 索引不应从 0 开始 | JDBC 索引从 1 开始 |

### 其他

| 序号 | 规则 | 说明 |
|------|------|------|
| 22 | 双前缀运算符检查 | `++i` 或 `i--` 应明确意图 |
| 25 | 应该使用 "notifyAll" | 使用 notifyAll 而非 notify |
| 27 | ".equals()" 不应用于测试 "Atomic" 类的值 | Atomic 类应使用 compareAndSet |
| 30 | "StringBuilder" 和 "StringBuffer" 不应使用字符进行实例化 | `new StringBuilder('c')` 应避免 |
| 32 | 关键字作为标识符 | 不能使用 Java 保留字 |

## 1.2 定制规则

### 项目结构

| 序号 | 规则 |
|------|------|
| 34 | 项目父依赖应为 `cacp-spring-boot-parent` 或基于该依赖的自定义项目 |
| 35 | 项目核心依赖为 `cacp-service-spring-boot-starter` 或 `cacp-job-spring-boot-starter` 两者之一 |
| 36 | 项目如果使用数据源，则必须依赖 `cacp-datasource-spring-boot-starter` |
| 37 | 项目目录命名应用按照 **"{应用编码}-{功能描述}-service/job"** 规则，且 `spring.application.name` 跟项目名保持一致 |

### 代码风格

| 序号 | 规则 |
|------|------|
| 38 | 代码中不应存在复杂的 if-else 和 for 循环嵌套（**嵌套层数大于 3**） |
| 39 | **代码中禁止使用 Date 类**，应使用 LocalDateTime 替换 |
| 40 | 字符串拼接，尤其是循环拼接，**应使用 StringBuilder 或 StringBuffer** |

### 异常处理

| 序号 | 规则 |
|------|------|
| 41 | 异常捕获后如需重新抛出自定义业务异常，则不必额外使用 log.error 记录，直接 `throw new BizException(...)` 即可；如不再抛出则应使用 `log.error` 记录 |

### 接口规范

| 序号 | 规则 |
|------|------|
| 42 | URL 路径名称要求：**全小写、不使用驼峰、使用 "-" 连接**（如 `/get-user`） |

### 数据库规范

| 序号 | 规则 |
|------|------|
| 43 | 数据库表要包含以下三个必备字段：`REC_VERSION`（版本号）、`REC_CREATE_TIME`（创建时间）、`REC_LAST_UPDATE_TIME`（最后更新时间） |

### 空指针与异常

| 序号 | 规则 |
|------|------|
| 44 | **空指针调用**：调用对象如果可能为空时，应在使用前进行判断 |
| 45 | **空异常**：变量初始值为空或曾判空，在其他逻辑分支使用变量时均应进行判空 |

### 资源管理

| 序号 | 规则 |
|------|------|
| 46 | 继承了 Closeable 接口的对象，在使用后**必须调用 close() 方法关闭对象** |
| 47 | 使用 String.split 方法返回的结果**必须进行长度判断** |

### 其他

| 序号 | 规则 |
|------|------|
| 48 | **在单实例类中禁止使用私有变量** |
| 49 | 跳转语句（return/break/continue）**不应出现在 "finally" 中** |

# 二、JavaScript 编码要求

## 2.1 通用规则

### 变量与声明

| 序号 | 规则 |
|------|------|
| 1 | 使用之前应定义变量 |
| 2 | 跟踪版权和许可标头的缺失 |
| 3 | 变量应明确声明 |
| 4 | 使用 "var" 声明的变量应在使用之前声明 |

### 控制流

| 序号 | 规则 |
|------|------|
| 5 | Switch case 应该以无条件的 "break" 语句结束 |
| 11 | 测试应包括断言 |
| 12 | "switch" 语句不应包含非大小写标签 |
| 13 | 断言应完成 |
| 17 | 函数返回不应该是不变的 |
| 18 | 循环不应该是无限的 |

### 数组与回调

| 序号 | 规则 |
|------|------|
| 6 | 数组方法的回调应该有返回语句 |

### 安全性

| 序号 | 规则 |
|------|------|
| 7 | XML 解析器不应容易受到 XXE 攻击 |
| 9 | 禁用 Angular 内置清理是安全敏感的 |
| 10 | 不应使用 Web SQL 数据库 |
| 14 | 硬编码的凭据对安全敏感 |
| 16 | 禁用 vue.JavaScript 内置逃脱是对安全敏感的 |

### 其他

| 序号 | 规则 |
|------|------|
| 8 | 不应使用八进制值 |
| 15 | "future reserved words" 不应用作标识符 |

# 四、重构检查清单

## Java 检查项

### 项目结构
- [ ] 父依赖使用 `cacp-spring-boot-parent`
- [ ] 核心依赖使用 `cacp-service-spring-boot-starter` 或 `cacp-job-spring-boot-starter`
- [ ] 数据源依赖 `cacp-datasource-spring-boot-starter`
- [ ] 项目名符合 "{应用编码}-{功能描述}-service/job" 规则

### 代码风格
- [ ] 无 if-else/for 嵌套超过 3 层
- [ ] 不使用 Date（使用 LocalDateTime）
- [ ] 循环拼接用 StringBuilder

### 控制流
- [ ] switch 有 break 或 return
- [ ] 不在 finally 中使用跳转语句
- [ ] 循环有终止条件

### 线程安全
- [ ] 不在字段本身同步
- [ ] 不使用字符串/装箱类型同步
- [ ] 持有多个锁时不调用 wait
- [ ] 使用 notifyAll 而非 notify
- [ ] ScheduledThreadPoolExecutor 核心线程数 > 0

### 资源管理
- [ ] Closeable 资源在使用后关闭
- [ ] String.split 结果判断长度

### 空指针
- [ ] 调用可能为空的对象前判断
- [ ] 判空后使用时再次判断

### 其他
- [ ] 方法不命名为 equal/hashcode
- [ ] 子类不覆盖父类字段
- [ ] 使用非短路逻辑 `&&`/`||`

## JavaScript 检查项

- [ ] 变量先声明后使用
- [ ] switch 有 break
- [ ] 数组回调有 return
- [ ] 无硬编码凭据
- [ ] 无八进制值
- [ ] 无无限循环
- [ ] 函数有实际返回值
