## 布局

- **顶部导航栏**：高 60px，背景 `#094194`，白色文字，flex 布局 justify-between align-center
- **侧边栏**：宽自适应（--el-aside），背景 `#094194`，菜单项高 44px
- **主内容区**（el-main）：padding `0`
- **搜索布局**（cacp-search__layout）：padding `16px`，宽高 100%
- **内容区**（cacp-search__content）：背景 `#fff`，边框 `1px solid #dcdfe6`，圆角 `5px`
- **搜索主区域**（cacp-search__main）：padding `15px 0`
- **搜索内区**（cacp-search__main .cacp-advance__layout）：padding `0 20px`

卡片内纵向间距：工具栏 → 表格 `12px` → 分页 `16px`

### 输入框 / 下拉框

高 28px，**`border: none`**，边框统一使用 `box-shadow: 0 0 0 1px #dcdfe6 inset`，圆角 3px，内边距 `0 10px`，字号 13px。
Hover `box-shadow: 0 0 0 1px #c0c4cc inset`；Focus `box-shadow: 0 0 0 1px #094194 inset`；
错误 `box-shadow: 0 0 0 1px #fa5e45 inset`；
禁用背景 `#f5f7fa`，文字 `#c0c4cc`；占位符颜色 `#a8abb2`。
禁止使用 `border` 绘制边框（避免与 `box-shadow` 叠加产生双线）。

下拉框 padding `4px 10px`，字号 14px；下拉选项高 28px，padding `0 10px`。
每页条数下拉宽 100px。

### 分页

左侧：共 N 条（13px `#666666`）。每页条数下拉宽 100px。
页码按钮 28×28px 圆角 3px；当前页 `#094194` 白字边框 `1px solid #094194`；其余白底边框 `1px solid #dcdfe6` 背景 `#f7f8fb`。
跳转框高 28px。整体 `flex; justify-content: space-between`，表格与分页间距 16px。
分页禁用：文字 `rgba(102,102,102,.5)`，背景 `rgba(247,248,251,.5)`。

### 弹窗

遮罩 `rgba(0,0,0,.25)`，背景 `#fff`，圆角 8px。
标题区：18px 700，头部 padding-top 20px、padding-bottom 15px，分割线 `1px solid #eee`（距顶 64px）。
内容区 padding-top 20px，字号 14px；底部操作区 padding-top 28px 右对齐。
宽度：字段 ≤4 → 520px；>4 → 680px。内容超出时滚动。
关闭按钮：32×32px 圆形，背景 `#f5f5f5`，hover 背景 `#eeeeee`。

## Toast（消息提示）

位置：页面顶部居中，内边距 `8px 15px`，圆角 3px，3s 自动消失。
图标字号 18px。

| 类型 | 背景 / 边框 | 文字/图标色 |
|------|------------|-------------|
| 成功 | `#e9f8f7` / `#d2f2ef` | `#1ebcaf` |
| 错误 | `#ffefec` / `#fedfda` | `#fa5e45` |
| 警告 | `#fff9ec` / `#fff3d8` | `#ffc23e` |
| 信息 | `#e5f2f9` / `#cfe5f9` | `#094194` |

## 表单校验

- 必填：标签前红色 `*`，输入框背景 `#fef7de`
- 错误：输入框 `box-shadow: 0 0 0 1px #fa5e45 inset`，下方红色提示文字
