前端项目中的弹窗统一使用 `cacp-dialog` 组件，该组件已封装了标准布局。

#### **1. 组件使用**

- **组件名称**：`cacp-dialog`
- **布局特性**：组件内部已提供默认布局结构。

#### **2. 属性配置**

- **宽度 (`width`)**：
  - 默认宽度：`360px`。
  - 自定义宽度：可根据业务需求自行设置，但需注意内容宽度不可过高，以保持视觉一致性。
- **高度控制**：
  - 必须设置最大高度（`max-height`）。
  - 当内容超出最大高度时，需显示滚动条。
- **尺寸调整 (`resizable`)**：
  - 必须设置为 `false`，禁止用户手动拖拽调整弹窗大小。
